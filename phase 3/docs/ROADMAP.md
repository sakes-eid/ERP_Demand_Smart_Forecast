# Roadmap

## 1. Current Status

- Phase 1 demand forecasting baseline exists.
- Phase 2 supply/procurement context exists.
- Phase 3 inventory control module is validated with no failed checks.

## 2. Phase 1 Improvements

- Stockout-censored demand correction.
- Forecast horizon demand totals.
- Demand uncertainty improvements.
- Event uplift refinement.
- Seasonality improvements.

## 3. Phase 2 Improvements

- Supplier return policy.
- Supplier-specific scenario data.
- Expedite availability and cost.
- Split-delivery constraints.
- Backorder aging.
- Supplier-specific cost/risk strategy mapping.

## 4. Phase 3 Improvements

- Supplier-ID-level scenario optimizer.
- Return, markdown, and scrap financial logic.
- Cost calibration.
- Historical learning loop.
- Purchase order recommendation bridge.

## 5. Phase 3 UI

- Manager dashboard.
- SKU detail page.
- Warehouse map page.
- Review queue page.
- Scenario comparison page.
- KPI page.

## 6. Later Phase 4

- Production/BOM logic.
- Semi-finished and finished-goods flow.
- Production capacity constraints.
- Make/buy decisions.
